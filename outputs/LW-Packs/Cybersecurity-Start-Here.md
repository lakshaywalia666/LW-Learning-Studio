# Cybersecurity & Hacking — start here

Prepared **6 November 2026**. Download [Cybersecurity-Full-Path.lw](Cybersecurity-Full-Path.lw) and open it in a build that supports legacy course imports. In builds with **Import .lw**, use **More → Library → Courses**, review the preview, and add the pack as a new course. The current editor defaults to direct task entry. The pack is unsigned and separate from the app.

This file has **100 sections, 600 topics (500 lessons plus 100 project topics), 1,600 tasks, 100 projects, 500 recall prompts and 600 self-assessment exercises**. There are no required checkbox lists. Study shows one task; open it to read, then tap Done after doing the work. Each lesson adds a deeper-study checklist with named concepts.

The target is beginner through advanced specialist work and independent research. Sections 01–50 build broad capability; sections 51–97 deepen systems, specialist engineering and research; sections 98–100 demand original inquiry, replication, peer defense and an expert evidence portfolio. These are evidence targets rather than a junior-role endpoint. No course can guarantee mastery of every field or cover every future discovery.

Start at section 01. Keep evidence in Notes, log actual study time separately and review difficult lessons. The estimate is about **2,325 planned task hours**, excluding additional reading, setup and repeated attempts; expert investigations may take much longer. This is a multi-year programme at part-time study. Marking Done does not verify expert competence; use **Cybersecurity-Mastery-Evidence.md** and the in-app evidence gates.

All included text works offline after import. Publisher reading and hosted exercises need internet. Most practical work needs a computer or a paper/synthetic alternative. Cloud accounts, paid tools and specialist hardware are optional. Practice uses owned or explicitly authorized environments. High-impact topics use simulations, bounded experiments and analysis.

For the complete topic list, deeper-study checklists, projects and references see **Cybersecurity-Syllabus.md**. The file covers offensive concepts, enterprise identity, web/API, cloud, containers, secure development, detection, hunting, incident response, forensics, malware, reverse engineering, exploitation models, wireless, mobile, macOS, hardware, OT, telecom, AI/agents/MCP, privacy, governance, financial systems and original research. Concise explanations orient study; detailed documentation and sustained independent work supply the depth.

Validation results and SHA256 are in **Cybersecurity-Validation.json**. Application course/workspace validators, all 1,600 task transitions, first-task Undo and export/reimport checks passed. A real phone import has not been performed for this edition. Keep a full workspace backup for personal progress; a course file contains curriculum only.
